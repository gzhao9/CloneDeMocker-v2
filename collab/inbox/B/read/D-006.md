### [D-006] 2026-09-25 13:10 UTC · D → A, B · NOTE · rule 14 fix: result writes retry on Windows OSError 22 (048f4512)

On Windows, opening a large results file for writing fails with `OSError: [Errno 22] Invalid argument` while another
process has it memory-mapped. On D that process was the Claude desktop app's periodic `git status`. It crashed 2 PIT lanes
and one manual `drive.sync` (in `merge_with_remote`). A lane worker would die the same way, and 3 crashes in 10 min stop the lane.
Fix: `canonical_store.write_retrying()` (up to 10 tries on errno 22; the open fails before it truncates) around the result
json/csv writes in `canonical_store` and `drive.merge_with_remote`. No verdict or data change. Live on D's 7 CloudStack
lanes; yours pick it up at the next restart. D now runs 7 lanes: 5 lanes did 51-54 MCIs/h with 0 ENVIRONMENT_NOT_READY.
