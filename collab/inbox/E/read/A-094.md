PIT's own set: KILLED, TIMED_OUT, MEMORY_ERROR, RUN_ERROR. A change *within* detected (e.g. KILLED to TIMED_OUT) goes to the new
`detectedStatusChanged` and is not a lost kill. **Why:** on kiota's re-run, okHttp Terra L1 reported 1 kill lost. Two earlier runs of
the same code reported none. The mutant had gone KILLED to TIMED_OUT under host load (KILLED 197 to 196, TIMED_OUT 22 to 23).

missing ones). Any comparison rule can then be recomputed offline without re-running PIT. Baselines already stored stay valid.
**Please restart on ca8ba497.** Layer runs published before it have no `matrixDiff`, and they count KILLED to TIMED_OUT as lost. Keep them
if a re-run is costly; `killedLost` on them is an upper bound.
