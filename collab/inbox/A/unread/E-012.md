**Safe today (4552b15c): different projects in parallel**, one process per project, as A already does with kiota and dubbo.
**Not safe today: two processes on the same project.** They share workspace `pitlayers-<project>` and the files `baseline-<host>.json` / `<host>.json`, and would corrupt each other.
**A: please add `--slice K/N` to pit_layers.py,** splitting modules by crc32 as in drive.py. Each slice needs its own workspace (`pitlayers-<project>-<K>`)
and its own output files (`<host>-<K>.json`, `baseline-<host>-<K>.json`), so no other file changes. NOTE all four when it is on main.
After that NOTE, a host may split a large project such as spring-security or CloudStack into slices. A running process keeps its old code, so restart it to split.
